# LINEヤフー広告 ConversionAPIタグ

LINEヤフー広告のConversionAPI用のタグです。  

設定について注意点があります。詳細は [ドキュメント](https://github.com/yahoojp-marketing/ads-data-management-api-documents/blob/main/docs_ja/conversion-api-tag.md) をご確認ください。

> [!IMPORTANT]
> LINE Conversion APIのパラメータも利用可能な、より精度の高い新しいコンバージョンAPIも提供しております。新規で導入する場合は、新しいコンバージョンAPIのご利用をおすすめします。  
> なお、本ドキュメントにある従来版コンバージョンAPIも引き続きご利用可能ですが、今後提供終了を予定しております。提供終了時期については決まり次第お知らせいたします。  
> 新しいコンバージョンAPIのドキュメントはこちら: https://ads-developers.yahoo.co.jp/ja/conversion-api/
